# API密钥列表UI/UX优化设计文档

**日期**: 2026-05-30
**状态**: 已批准
**版本**: 1.0

---

## 1. 概述

### 背景
"编辑OpenAI兼容提供商"页面下方的API密钥列表区域存在以下问题：
- 密钥明文显示，存在安全隐患
- 表格列拥挤，信息交错重叠，可读性差
- 权重输入框过宽，易误输入
- 代理URL占据主表空间，大部分情况不需要
- 删除操作缺乏确认机制

### 目标
在不破坏现有功能的前提下，全面提升API密钥列表的：
- **安全性**：密钥密码遮蔽
- **可读性**：状态徽章清晰、布局更宽松
- **交互性**：步进器输入、二次确认删除
- **专业性**：复制功能、眼睛图标切换

---

## 2. 布局结构

### 当前布局
```
| # | 状态(46px) | 密钥(最小320px) | 代理(120px) | 权重(120px) | 操作 |
```

### 优化后布局
```
| # | 状态(优先级) | 密钥(聚焦) | 权重(紧凑) | 操作 |
```

**列定义**：
- `#`: 46px，居中序号
- `状态`: 优先级最高，展示状态Badge（空闲/成功/失败/加载中）
- `密钥`: 自适应宽度，包含输入框+眼睛图标+复制图标
- `权重`: 固定80px，数字步进器
- `操作`: 测试按钮 + 删除按钮（带二次确认）

**代理URL处理**：
- 从主表格移至"展开高级设置"区域
- 默认折叠，节省空间

## 3. 组件详细设计

### 3.1 状态徽章 (StatusBadge)

**类型**：
| 状态 | 样式 | 内容 |
|------|------|------|
| `idle` (空闲) | 灰色背景 | 未测试 |
| `loading` (加载中) | 蓝色背景+旋转动画 | 测试中... |
| `success` (成功) | 绿色背景 | 可用 231ms |
| `error` (失败) | 红色背景 | 异常 (悬浮显示错误信息) |

**样式细节**：
- 圆角胶囊形状 (border-radius: 999px)
- 内边距: 4px 12px
- 字号: 12px
- 错误状态悬浮显示完整错误信息 (Tooltip)

### 3.2 密钥输入框组合

```
┌──────────────────────────────────────────────────┐
│ [密码输入框........................] [👁] [📋]   │
└──────────────────────────────────────────────────┘
```

**组成**：
- **输入框**: `type="password"` 或 `type="text"`（根据切换状态）
- **眼睛图标**: 切换密码可见性
- **复制图标**: 一键复制到剪贴板

**行为**：
- 默认：密码遮蔽显示 (`sk-0Z1W•••••••aF1`)
- 点击眼睛：切换为明文显示
- 点击复制：复制完整密钥到剪贴板，显示Toast提示

### 3.3 权重数字步进器

```
┌─────────────────┐
│  [−]  [ 1 ]  [+] │
└─────────────────┘
```

**行为**：
- 点击 `+`/`-` 按钮：权重增减1
- 直接输入：允许数字输入
- 最小值: 1
- 最大值: 无限制（或100）
- 宽度: 固定80px

### 3.4 代理URL展开区

```
┌────────────────────────────────────────┐
│ [展开] 可选代理 URL                    │
└────────────────────────────────────────┘
              ↓ 展开后
┌────────────────────────────────────────┐
│ [收起] 可选代理 URL                    │
│ ┌────────────────────────────────────┐ │
│ │ 输入框...                          │ │
│ └────────────────────────────────────┘ │
└────────────────────────────────────────┘
```

**行为**：
- 默认折叠状态
- 点击"展开"显示代理URL输入框
- 占主表右侧空间，不影响主布局

### 3.5 删除操作二次确认

**流程**：
1. 点击"删除"按钮
2. 弹出确认Modal
3. 内容: "确定要删除此密钥吗？"
4. 按钮: "取消" / "确认删除"
5. 确认后执行删除操作

### 3.6 测试按钮

**状态**：
- 默认: `variant="secondary"`
- 加载中: 显示loading状态
- 不可用: 未填写密钥或无模型时禁用
